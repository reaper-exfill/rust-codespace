# rust-codespace

A GitHub Codespaces configuration for Rust development.

## What's included
- Official Rust dev container image (mcr.microsoft.com/devcontainers/rust)
- Rust Analyzer extension for code analysis and completion
- GitHub Copilot extension for AI pair programming

## How to use
1. Click the green **Code** button on this repository.
2. Open the **Codespaces** tab and click **Create codespace on main**.
3. Wait for the container to build, then start coding in your browser.
4. Check the setup by running `rustc --version` in the terminal.
